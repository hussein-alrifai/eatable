# Eatable Roadmap (updated at v8)

## Working baseline

- v1: responsive bilingual recipe discovery prototype.
- v2: Supabase email accounts and cloud favorites.
- v3: community recipe submissions and administrative approval.
- v4: photographs, revision requests, private media workflow.
- v5: unified recipe catalog, curated data and community ingredient indexing.
- v6: bilingual administrator Curated Recipe Editor, drafts and publishing.
- v7: administrator-curated photo uploads, private drafts and public covers.
- v8: private editorial QA dashboard, review checklist and catalog export.

## Next substantive work

1. Convert the initial demo recipes into fully tested, bilingual, photographed recipes.
2. Expand to the original 60–100 curated recipes with a strong Lebanese Table collection, using the `RECIPE_BACKLOG_80.md` as a candidate list, not as verified content.
3. Strengthen ingredient aliases, optional ingredients, allergy notices and pantry-match behavior based on real search tests.
4. Run accessibility, mobile and performance audits; add SEO-friendly recipe metadata after validating content.
5. Add useful user tools (shopping list, pantry quantities, cooking timer) before expensive AI features.
6. Only after the core recipe platform is dependable, plan restaurant integration as a separate commerce module.
