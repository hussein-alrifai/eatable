# Eatable — National cuisine taxonomy

The recipe `cuisine` field stores a specific national culinary tradition/variant, **not** a broad continent or placeholder category. The site shows a translated name and corresponding flag.

Cuisine values are case-sensitive. Use the exact **English ID** from `cuisine-patch/cuisines.json` for the importer.

**Important:** Country-level culinary taxonomies are a user-interface aid. Many dishes are shared across modern borders. These fields do not make exclusive origin or cultural ownership claims.

Some existing v27 and seeded recipes used the generic labels `Other` or `Middle Eastern`; the files in this pack do **not** use them as new import classifications. Existing published rows must be reviewed separately rather than automatically reassigned.
