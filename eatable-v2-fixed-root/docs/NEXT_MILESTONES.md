# Next Eatable technical milestones

1. **Phase 2B — Recipe data migration.** Normalized cuisines, ingredients, translations, recipe versions, servings, steps and publishing status; seed curated catalog. Public RLS read access only for published recipes. The demo favorites slug keys will migrate to recipe UUIDs once all slugs have mapped IDs.
2. **Phase 2C — Recipe submissions.** Draft editing, pending state, requests for changes, moderation log and admin-only publishing. Build and test privilege escalation and status-transition protections; avoid granting member updates to admin columns.
3. **Phase 2D — Photo storage and reviews.** Upload bucket rules, file ownership, malware/format/size validation, moderation, abuse reporting, reviews, backups and privacy/legal text.
4. **Phase 3 — Enhancements.** Saved pantry, substitutions, shopping lists, timer, Arabic localization, and full 60–100 recipe launch collection.
5. **Phase 4 — Restaurant.** Separate menu, ordering, payments and inventory boundaries. Link recipes to menu items, never reuse recipes as purchasable products.
